<p align="center">
  Proyecto académico individual desarrollado durante la formación en <b>SoyHenry</b>. Consiste en la construcción de una aplicación full stack para la gestión integral de turnos médicos en una clínica, implementando autenticación de usuarios, agendado de turnos y un panel personal limpio y profesional.

## ⚙️ Funcionalidades Principales

* **Registro e Inicio de Sesión:** Autenticación segura de usuarios con manejo de estado global y validaciones de formularios en tiempo real.
* **Agendamiento Inteligente:** Lógica interactiva para reservar turnos médicos con restricción de tiempo (mínimo 24 hs de anticipación).
* **Dashboard de Turnos:** Panel personal donde el usuario puede consultar el historial de sus turnos activos, pendientes o cancelados.
* **Interfaz Adaptativa:** Diseño limpio y amigable para el paciente, desarrollado con CSS Modules y Bootstrap.

---

## 🚀 Tecnologías Utilizadas

* **Frontend:** React.js, Vite, Bootstrap, CSS Modules, Axios, SweetAlert2
* **Backend:** Node.js, Express, TypeScript, TypeORM
* **Base de Datos:** PostgreSQL
* **Control de Versiones:** Git / GitHub

## 🛠️ Instalación

1. **Clonar el repositorio**

```bash
git clone https://github.com/pi-rym/PM3-RocioArias7.git
```

2. **Configurar las variables de entorno** en `back/.env`.

3. **Iniciar el backend**

```bash
cd back
npm install
npm run dev
```

4. **Iniciar el frontend**

```bash
cd front/miproyecto
npm install
npm run dev
```
