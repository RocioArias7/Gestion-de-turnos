# 🏥 Turnos Clínica — Proyecto Módulo 3

Proyecto académico individual de la formación en **SoyHenry**.
Consistió en la construcción de una **aplicación full stack para la gestión de turnos en una clínica**, implementando autenticación de usuarios, agendado de turnos y panel personal.

## 🚀 Tecnologías

- **Frontend:** React, CSS Modules, Bootstrap, Axios, SweetAlert2
- **Backend:** Node.js, Express, TypeScript, TypeORM
- **Base de datos:** PostgreSQL
- **Control de versiones:** Git / GitHub

## ⚙️ Funcionalidades principales

- Registro e inicio de sesión de usuarios
- Agendar turnos médicos
- Consultar mis turnos activos

## 🛠️ Instalación

1. Clonar el repositorio
```bash
git clone https://github.com/pi-rym/PM3-RocioArias7.git
```
2. Configurar variables de entorno en `/back/.env`
3. Iniciar el backend
```bash
cd back && npm install && npm run dev
```
4. Iniciar el frontend
```bash
cd front && npm install && npm start
```
